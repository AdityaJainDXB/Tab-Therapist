What is Tab Therapist?

Tab Therapist is a Chrome extension designed to help you manage your browser tabs and keep your browser organized.

It can:

  • 📊 Analyze your open tabs
  • 🩺 Give your tabs a health score
  • 🔍 Detect duplicate tabs
  • 🧹 Clean duplicate tabs
  • 🗂️ Organize tabs into groups
  • 💾 Save tabs for later
  • 💬 Give humorous recommendations

⬇️ How to Download & Install

Tab Therapist is currently available as an unpacked Chrome extension.

1 Open the GitHub repository

Click the button below to open the official Tab Therapist GitHub repository.

Open Tab Therapist on GitHub →

2 Download the project

On GitHub, click the green Code button and select Download ZIP.

3 Extract the ZIP

Find the downloaded ZIP file and extract it. You should have a folder containing: 

manifest.json
popup.html
popup.css
popup.js
icon.jpeg
index.html
4 Open Chrome Extensions

Open Google Chrome and enter: 

chrome://extensions
5 Enable Developer Mode

Turn on Developer mode using the switch in the top-right corner.

6 Load Tab Therapist

Click Load unpacked.

Select the folder you extracted in Step 3. Make sure the folder contains manifest.json.

7 You're done!

Tab Therapist should now appear in your Chrome extensions. Click the puzzle-piece icon 🧩 in Chrome and pin Tab Therapist for easy access.

⚠️ Important: This is a developer/unpacked installation. Chrome may display a message saying that developer mode extensions are enabled. This is normal for this installation method.

🛠️ Requirements

  • Google Chrome
  • Developer Mode enabled
  • The Tab Therapist project folder
